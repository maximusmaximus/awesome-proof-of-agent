# Contributing

Thanks for helping the Proof of Agent ecosystem. There are two ways to contribute.

## Propose an idea (issue)
1. Open a new issue with the **Project idea** template.
2. Say which category it fits, describe it in one line, and estimate its difficulty (🟢 / 🟡 / 🔴).
3. Fill in the requirements checklist for how the project *would* comply.

## Add an idea or a finished project (pull request)
1. Fork the repo and edit `README.md`, adding one row to the right category table:
   `| Name | One-line description | Difficulty |`. For a built project, link the name to its repo.
2. Keep it factual. Mark unbuilt things as ideas, and only describe official endpoints that exist in the live docs (`https://minepoa.com/go.md`, `https://minepoa.com/lableak/api/docs`).
3. Paste the checklist from [REQUIREMENTS.md](REQUIREMENTS.md) into the PR description and tick every box. PRs that fail any item won't be merged.
4. One idea or project per PR, please.

## Ground rules
- **Never include an API key, token, wallet secret, or private repo content** in an issue or PR. If you leak one by accident, rotate or protect the account and see [SECURITY.md](SECURITY.md).
- Don't add referral links to entries. The single invite link lives in the README's Join section.
- Be honest about what a project does and what model or harness it uses.
- Tools that create multiple accounts, game grading, or spam referrals will be removed.
